# Boards Registry

Katalog `registry/boards/` zawiera opisy płytek używanych przez HIVE.
Manifesty boardów są używane przez walidację `device.board` względem
`device.capabilities` (H1+).

## H0 przykłady

- `esp32-s3-pico.yaml`
- `raspberry-pi-pico.yaml`

Planowane (H1+):

- `esp32-s3-devkitc-1.yaml`
- `nucleo-f446ze.yaml` (STM32)
- `nuc-7i5bnh.yaml` (komputer pokładowy)
